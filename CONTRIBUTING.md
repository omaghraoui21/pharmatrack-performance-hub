# Contributing

Thank you for considering a contribution to PharmaTrack Performance Hub.

This project welcomes people who care about pharmaceutical operations, industrial performance, OEE/TRS, daily management systems, and open-source manufacturing tools.

## Contribution ideas

- Improve dashboard layout
- Add KPI examples
- Add OEE/TRS calculation tests
- Create safe fictional datasets
- Improve documentation for production teams
- Add downtime or quality-loss categories
- Suggest GMP-friendly design constraints

## Project principles

- Keep calculations transparent.
- Use fictional demo data only.
- Avoid confidential site, batch, supplier, employee, or patient data.
- Treat GMP-related outputs as decision support unless formally validated.
- Prefer practical workflows over complex enterprise features.

## Pull request checklist

- Explain the production problem being solved.
- Keep changes small and reviewable.
- Update documentation if behavior changes.
- Do not include real confidential manufacturing data.
- Add screenshots for visible dashboard changes when useful.
